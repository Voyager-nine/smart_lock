# CH32串口移植经验

## 1. USART3 引脚
- 默认：`PB10=TX`，`PB11=RX`
- 可重映射到：`PC10/PC11` 或 `PD8/PD9`
- `PA2/PA3` 不能用于 `USART3`，它更常见于 `USART2`
- 就是不能随意指定引脚，应查看芯片手册，不同外设有其指定引脚

## 2. 不重映射也要配 GPIO
不重映射只是用默认引脚，不代表可以不配引脚。

```c
//使能外设时钟
RCC_APB1PeriphClockCmd(RCC_APB1Periph_USART3, ENABLE);
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);

//配置TX引脚
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_10;
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;
GPIO_Init(GPIOB, &GPIO_InitStructure);

//配置RX引脚
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_11;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IN_FLOATING;
GPIO_Init(GPIOB, &GPIO_InitStructure);
```

## 3. GPIO 初始化注意点
- `TX` 用 `GPIO_Mode_AF_PP`(复用推挽输出)
- `RX` 用输入模式，如 `GPIO_Mode_IN_FLOATING`（浮空输入）
- 改一次 `GPIO_InitStructure`，就要调用一次 `GPIO_Init()`
- 不然前面的配置会被后面的覆盖

## 4. 工程里的打印函数
这个工程里直接用 `printf()`。

实际链路是：
- `printf()`
- `_write()`
- `USART_SendData(USART3, ...)`

所以想让打印走 `USART3`，关键是把 `DEBUG` 配到 `DEBUG_UART3`（在debug.h中）。

## 5. 也可以直接用 USART_SendData

**Peripheral中即可查看各个模块封装好的函数**

如果只发单个字节，可以不用 `printf()`，直接发送：

```c
while(USART_GetFlagStatus(USART3, USART_FLAG_TXE) == RESET);
USART_SendData(USART3, temp);
```

注意：
- `USART_SendData()` 适合发单个字节
- 发字符串需要自己循环发送
- 标准库里没有现成的 `USART_SendString()`

## 6. 接收数据为什么发 1 打印 50
因为串口收到的是字符，不是数值。

- `'1'` 的 ASCII 是 `49`
- `49 + 1 = 50`
- `printf("%d", temp)` 打印出来就是 `50`

## 7. 正确处理方式
如果想把字符数字转成数值再加 1：

```c
if(temp >= '0' && temp <= '9')
{
    temp = (temp - '0') + 1;
    printf("%d\r\n", temp);
}
```

如果只是想回发下一个字符：

```c
temp += 1;
printf("%c\r\n", temp);
```

## 8. 结论
- `USART3` 默认用 `PB10/PB11`
- `PA2/PA3` 不能直接给 `USART3` 用
- 不重映射也必须初始化 GPIO
- `TX` 和 `RX` 模式不同
- `printf("%d")` 打印数值，`printf("%c")` 打印字符
- `USART_SendData()` 可直接发单字节
